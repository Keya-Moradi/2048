How to Play 2048

Welcome to the 2048 game! Your goal is to combine tiles with the same number to create a tile with the value of 2048.

Game Setup

  • The game starts with a 4x4 grid, initially containing two tiles, each showing a number (either 2 or 4).
  • New tiles will appear after every move you make, in a random empty position on the grid.

How to Play

  1. Objective: Slide numbered tiles on a grid to combine them and create a tile with the number 2048.
  2. Desktop Controls: Use the arrow keys on your keyboard to move tiles in the corresponding direction (up, down, left, right).
  3. Mobile Controls: Swipe in any direction to move tiles.
  4. Merging Tiles: When two tiles with the same number collide while moving, they merge into one tile with a value equal to their sum (e.g., two tiles with '2' merge to become a '4'). Each successful merge increases your score by the value of the merged tile.
  5. Game Progression: After every move, a new tile with a value of either 2 or 4 will randomly appear on an empty spot on the grid. The game ends if there are no empty spaces left on the grid and no possible merges.
  6. Winning the Game: The goal is to create a tile with the number 2048 through merging. When you achieve a tile of 2048, a "You Win!" message will appear. You can continue playing to reach higher scores!
  7. Game Over: If the grid is full and no more merges can be made, the game will display a "Game Over!" message.

New Features

  • Undo: Take back your last move (up to 10 moves)
  • High Score: Your best score is automatically saved
  • Best Tile: Track the highest tile you've ever achieved
  • Auto-Save: Game state is saved automatically
  • Mobile Support: Play with touch gestures on mobile devices
  • Continue After Win: Keep playing after reaching 2048!

Additional Features

  • You can restart the game at any time by clicking the Restart button, which will reset the grid and score.
  • To return to the welcome page, click the Back to Welcome Page button.

Enjoy playing and good luck reaching 2048!
